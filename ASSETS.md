# Caramelldansen Canonical Assets

This repository tag provides canonical, immutable media assets for the Caramelldansen Terminal Player.

### Assets Included
- `caramell_dansen.bin` (140 MB) — Pre-rendered CDBP v1 TrueColor binary cache
- `caramell_dansen.mp3` (4.8 MB) — Stereo audio track
- `caramell_dansen.mp4` (25 MB) — High-definition clean source video

*Note: Application source code is maintained on the `main` branch.*
